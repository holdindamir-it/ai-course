Урок 5.5. Генерация документов и ответов по шаблону с помощью OpenAI

Генерация контента через OpenAI: принципы работы

Интеграция с OpenAI в n8n работает как посредник между входными данными (Webhook) и алгоритмом обработки естественного языка. Вы передаете текст в модель через API, указываете системную инструкцию (System Prompt), а модель возвращает структурированный ответ, который затем парсится (разбирается) нодами для дальнейших действий.

Технически это происходит так: текст из Webhook упаковывается в JSON-объект, отправляется на сервер OpenAI, где обрабатывается нейросетью согласно заданным вами параметрам (температура, модель), и возвращается обратно в n8n как массив данных, доступных для использования в следующих узлах сценария.

Интерфейс и настройка ноды OpenAI

  • Credential (Учетные данные): Выберите созданный API Key. Если он отсутствует, нажмите "Create New", вставьте ключ, полученный в личном кабинете OpenAI, и сохраните.
  • Resource (Ресурс): Выберите Chat. Это основной интерфейс для работы с текстовыми моделями.
  • Operation (Операция): Установите значение Complete.
  • Model (Модель): Выберите версию, например, gpt-3.5-turbo или gpt-4o-mini для базовых задач классификации.
  • Messages (Сообщения): Это основной блок логики. Вам нужно добавить два типа сообщений через кнопку "Add Message":
    • System: Здесь прописывается инструкция. Пример: "Ты классификатор. Анализируй текст и ответь строго одним словом: 'тариф' или 'отзыв'".
    • User: Сюда через выражение (Expression) передается текст, пришедший из ноды Webhook.
  • Options (Дополнительные параметры):
    • Temperature: Установите на 0. Это критически важно для классификации, чтобы исключить вариативность и сделать ответы модели предсказуемыми.

Логика передачи данных в ноду Switch

После получения ответа от OpenAI, данные сохраняются в объекте JSON. Чтобы направить их в Switch:

  • Откройте настройки ноды Switch.
  • В поле Data Type выберите String.
  • В поле Value 1 вставьте выражение, ссылающееся на поле ответа OpenAI (обычно это {{ $json.message.content }}).
  • В разделе Rules выберите String -> Equal.
  • Для правила 1 укажите значение тариф и направьте поток в Telegram.
  • Для правила 2 укажите значение отзыв и направьте поток в Google Sheets.

Пошаговая настройка цепочки

  • В рабочей области n8n перетащите ноду Webhook. В поле HTTP Method выберите POST. Скопируйте Test URL для вставки в Postman.
  • Добавьте ноду OpenAI, соедините её с Webhook. В настройках сообщения User нажмите на иконку шестеренки рядом с полем ввода и выберите Add Expression. В открывшемся окне перетащите переменную body из входных данных Webhook.
  • Добавьте ноду Switch. В поле Data Type выберите String. В поле Value 1 через Expression выберите путь: {{ $json.message.content }}.
  • В разделе Rules нажмите Add Rule дважды. В первом правиле выберите Equals и впишите тариф. Во втором — Equals и впишите отзыв.
  • К выходам Switch (названным согласно правилам) подключите соответствующие ноды: Telegram (отправка сообщения) и Google Sheets (добавление строки).

Технические причины сбоев и методы устранения

  • Несоответствие формата ответа: OpenAI может добавить лишние пробелы или точки в ответ.
    Решение: В настройках ноды OpenAI измените системный промпт на: "Ответь строго одним словом без знаков препинания и пробелов: 'тариф' или 'отзыв'". В ноде Switch используйте функцию .trim() в выражении (например, {{ $json.message.content.trim() }}).
  • Тайм-аут API: Модель долго генерирует ответ, и Webhook закрывает соединение.
    Решение: В настройках ноды Webhook установите параметр Respond в режим Immediate Response, чтобы не ждать окончания обработки сценария.
  • Отсутствие данных на входе: Если в Webhook не пришло поле с текстом, нода OpenAI выдаст ошибку 400.
    Решение: Добавьте ноду If сразу после Webhook. Проверьте наличие ключа body.message. Если он пуст — направьте поток в Error Trigger или ноду HTTP Respond с кодом 400.

Практическое задание для закрепления

  • Создайте в Telegram-боте канал или чат, куда будут приходить уведомления по тарифам.
  • В Google Таблице создайте столбцы "Дата" и "Текст отзыва", настройте подключение через ноду Google Sheets (OAuth2).
  • Протестируйте сценарий через Postman, отправив JSON: {"message": "Сколько стоит подписка?"} и убедитесь, что сработала ветка Telegram.
  • Отправьте JSON: {"message": "Ваш сервис ужасен"} и проверьте появление новой строки в Google Таблице.
  • Если данные попадают в "пустую" ветку Switch, добавьте ноду Sticky Note (заметка) на поле и пропишите в ней условие обработки неизвестных сообщений.
