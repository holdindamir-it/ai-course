Урок 2.3. Google Forms -> Google Sheets -> уведомление: полная связка

Суть автоматизации передачи данных из Google Forms в Google Sheets

Связка Google Forms и Google Sheets работает как поток событий: форма выступает источником данных (триггером), а таблица — местом их структурированного хранения. В n8n процесс выглядит как цепочка: нода Google Forms Trigger постоянно опрашивает API формы на наличие новых ответов. Как только форма получает заполненные поля, n8n мгновенно считывает эти данные в формате JSON и передает их в ноду Google Sheets, которая выполняет операцию Append (добавление новой строки).

Интерфейс и логика настройки узлов

Для реализации данной связки используются следующие компоненты интерфейса n8n:

  • Google Forms Trigger (нода-источник): В поле Form ID необходимо указать идентификатор формы из её URL (строка символов после /d/ и до /edit). Нажатие кнопки Listen for Event переводит ноду в режим ожидания: до момента получения реального ответа через заполнение формы сценарий не активируется.
  • Google Sheets (нода-приемник):
    • В поле Resource выбирается Row, в Operation — Append.
    • Document ID: Выбор таблицы через встроенный поиск или вставка ссылки на Google Таблицу.
    • Sheet Name: Точное название вкладки в файле (например, Sheet1).
    • Mapping: В блоке Columns нажимается кнопка Add Column для каждой переменной из формы. В поле Value перетаскиваются (drag-and-drop) соответствующие ключи из выходных данных предыдущей ноды (Trigger).
  • Управление потоком: Для проверки корректности передачи данных используется кнопка Execute Workflow. В панели Output справа отображается сформированный JSON-объект, который нода передает дальше. Если данные отобразились в интерфейсе Google Sheets, значит, соединение между API Google и n8n установлено корректно.

Пошаговая инструкция настройки

  • Откройте n8n и добавьте ноду Google Forms Trigger. В выпадающем меню Credential выберите созданное подключение к Google API.
  • В поле Form ID вставьте ID вашей формы. Нажмите кнопку Listen for Event.
  • Откройте форму в режиме заполнения (через ссылку «Просмотреть»), введите любые тестовые данные и отправьте форму. Вернитесь в n8n: нода должна отобразить входящие данные в виде списка ключей и значений.
  • Добавьте ноду Google Sheets, соедините её с триггером. Выберите Resource: Row, Operation: Append.
  • В поле Document выберите из списка вашу таблицу. В Sheet укажите название листа (например, Лист1).
  • Нажмите кнопку Add Column для каждого поля формы. В поле Value нажмите на иконку «плюс» (Expression) и выберите соответствующие поля из данных, полученных от триггера.
  • Нажмите Execute Node для теста. Проверьте таблицу: строка с данными должна появиться автоматически.

Типичные ошибки и способы их устранения

  • Ошибка аутентификации (403 Permission Denied): Возникает, если аккаунт Google, подключенный в n8n, не имеет прав на редактирование таблицы или просмотр формы. Решение: Проверьте раздел Credentials в n8n, убедитесь, что вы предоставили все права при связывании аккаунта (особенно drive.file и spreadsheets).
  • Несоответствие имен столбцов: Вы пытаетесь записать данные в столбец, которого нет в таблице, или название в ноде отличается от заголовка в первой строке таблицы. Решение: Убедитесь, что в первой строке Google Sheets прописаны заголовки, и они в точности совпадают с названиями, указанными в маппинге ноды n8n.
  • Задержка API (Webhook delay): Форма заполнена, но n8n не реагирует. Решение: Нажмите кнопку Listen for Event повторно, чтобы обновить соединение, и убедитесь, что сценарий в n8n находится в статусе Active (переключатель в верхнем правом углу интерфейса).

Практическое задание

  1. Создайте в Google Таблице три заголовка: Date, User, Message.
  2. Настройте Google Forms так, чтобы в ней было три соответствующих поля для ввода.
  3. Настройте n8n сценарий для автоматического переноса данных из формы в соответствующие колонки таблицы.
  4. Удалите последнюю добавленную строку в таблице вручную, перезапустите сценарий в n8n, нажав Execute Workflow, и убедитесь, что данные успешно записались снова.
