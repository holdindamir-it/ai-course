Урок 5.1. Подключение OpenAI к n8n: получаем API-ключ, делаем первый запрос

Суть интеграции OpenAI и n8n

OpenAI API предоставляет доступ к вычислительным мощностям языковых моделей через протокол HTTP. n8n выступает в роли клиента, который отправляет структурированный JSON-запрос к серверам OpenAI, получает ответ и передает его дальше по цепочке автоматизации.

Взаимодействие происходит через Credential — токен доступа, который подтверждает подлинность запроса, и ноду OpenAI, которая выполняет роль интерфейса для формирования тела запроса (модель, температура, системные инструкции и сам текст пользователя).

Получение ключа API

  • Перейдите на платформу platform.openai.com.
  • В разделе API Keys нажмите кнопку Create new secret key.
  • Скопируйте полученную строку и сохраните её локально — повторно она не отобразится.

Настройка в интерфейсе n8n

Добавление Credentials

  • В рабочем пространстве n8n откройте левое меню, перейдите в раздел Credentials.
  • Нажмите Add Credential и выберите в поиске OpenAI API.
  • В поле API Key вставьте ключ, полученный ранее. Нажмите Save.

Настройка ноды OpenAI

  • Добавьте ноду OpenAI на холст (Canvas) через поиск в правой панели.
  • В поле Credential for OpenAI API выберите созданный ранее объект доступа.
  • В поле Resource выберите Chat.
  • В поле Operation выберите Complete.
  • В разделе Options задайте Model (например, gpt-4o или gpt-3.5-turbo).
  • Используйте поле Messages для динамической передачи данных:
    • Role: укажите system для задания правил поведения модели.
    • Role: укажите user и в поле Content используйте выражение (Expression) для вставки данных из предыдущих нод, например, {{ $json.body.message }}.

Пошаговая инструкция: создание первого запроса

  • Выберите ноду OpenAI на холсте. В правой панели настроек убедитесь, что в поле Resource выбрано Chat, а в Operation — Complete.
  • В блоке Messages нажмите кнопку Add Message.
  • В первой строке Role выберите system, а в Content впишите инструкцию: "Ты — технический ассистент".
  • Нажмите Add Message еще раз. Во второй строке в Role выберите user.
  • Нажмите на иконку Expression (шестеренка или значок цепочки) рядом с полем Content. В открывшемся редакторе выберите из списка слева ноду Webhook и поле, содержащее входящий текст. Нажмите Save.
  • Нажмите кнопку Execute Node внизу панели настроек, чтобы отправить тестовый запрос к OpenAI.

Почему это ломается: типичные ошибки

  • Ошибка 401 Unauthorized: API-ключ неверный или истек срок его действия. Решение: Перейдите в Credentials, выберите свой объект OpenAI и заново вставьте ключ, убедившись, что в начале и конце нет лишних пробелов.
  • Ошибка 429 Too Many Requests: Исчерпан лимит средств (Credits) на аккаунте OpenAI. Решение: Зайдите в личный кабинет platform.openai.com, проверьте раздел Billing и наличие активных средств на балансе.
  • Ошибка "Model not found": Выбранная модель устарела или недоступна на текущем тарифе. Решение: В ноде OpenAI в поле Model вручную введите актуальное название (например, gpt-4o-mini), так как выпадающий список иногда не обновляется после изменения настроек аккаунта.

Практическое задание

  • Создайте цепочку: Webhook -> OpenAI -> Respond to Webhook.
  • В ноде Respond to Webhook настройте ответ так, чтобы он возвращал только поле Content из ответа OpenAI (используйте Expression для выбора поля output.content).
  • Запустите тест: отправьте JSON-запрос через любой инструмент (например, Postman или расширение браузера), передав сообщение "Привет, как дела?".
  • Откройте вкладку Execution Data в n8n и проверьте, пришел ли корректный JSON от OpenAI и правильно ли он транслируется в финальный ответ.
  • Измените модель в ноде OpenAI на другую (например, gpt-4o-mini) и убедитесь, что структура ответа в логах осталась прежней.
