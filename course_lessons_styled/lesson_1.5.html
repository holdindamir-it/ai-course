Урок 1.5. Циклы и массивы (нода Loop / Split in Batches)

Суть инструментов Split In Batches и Loop

В автоматизации n8n данные часто приходят в виде массивов — списков объектов (например, список из 100 пользователей). Стандартные ноды обрабатывают весь массив целиком. Если требуется применить логику к каждому элементу по отдельности (например, отправить email каждому пользователю из списка), используются ноды цикла.

Split In Batches — это нода-распределитель. Она принимает массив на вход и «откусывает» от него заданное количество элементов за один проход. Loop (нода Loop Over Items) автоматически перебирает массив поэлементно. Когда ноды внутри цикла завершают работу, управление возвращается в начало, пока массив не будет исчерпан.

Разбор интерфейса и логики работы

  • Split In Batches:
    • Batch Size: поле ввода, определяющее количество элементов, которые пройдут через ноду за один цикл. Установка значения "1" заставляет систему обрабатывать данные строго по одной записи.
    • Output: нода имеет два выхода. Верхний выход передает порцию данных в поток обработки. Нижний выход (Loop) замыкается обратно на вход потока, чтобы повторить итерацию.
  • Loop Over Items:
    • Эта нода заменяет ручную настройку Split In Batches. Она автоматически определяет количество элементов в массиве.
    • Loop выход: этот порт соединяется с последней нодой в цепочке обработки (обычно с нодой типа Set или HTTP Request).
    • Finished выход: активируется только тогда, когда все элементы массива были последовательно обработаны. К нему подключаются ноды завершения (например, отчет о выполнении).
  • Особенности работы с данными:
    • В процессе цикла ноды имеют доступ к текущему элементу через выражение {{ $json.имя_поля }}.
    • Чтобы избежать бесконечного цикла, логическая связь всегда должна быть замкнута через обратную стрелку (соединение нижнего порта ноды цикла с входом первой ноды в теле цикла).

Пошаговая настройка цикла

Для создания рабочего цикла в n8n выполните следующие действия:

  • Добавьте ноду Split In Batches сразу после ноды, получающей массив данных (например, HTTP Request).
  • В поле Batch Size ноды Split In Batches установите число 1. Это обеспечит поочередную обработку каждого элемента.
  • Соедините верхний выход (Output) ноды Split In Batches с нодой, которую вы хотите применить к каждому элементу (например, нода Set).
  • Протяните связь от выхода ноды Set обратно ко входу ноды Split In Batches. Это создает петлю обратной связи (Loop).
  • Запустите процесс кнопкой Execute Workflow. Нода Split In Batches будет автоматически переключаться между порциями данных до тех пор, пока массив не опустеет.

Типичные ошибки и способы их устранения

  • Бесконечный цикл: Возникает, если вы не соединили выход последнего действия с входом ноды цикла. Решение: проверьте наличие визуальной линии, возвращающейся к Split In Batches.
  • Потеря данных из-за перезаписи: Происходит, если в ноде Set вы не используете опцию Append to Existing или сохраняете результат в переменную с тем же именем. Решение: используйте разные имена полей для хранения промежуточных результатов каждой итерации.
  • Неверный ввод (Input Type): Нода цикла выдает ошибку, если на вход поступает объект вместо массива. Решение: проверьте через вкладку Input, что предыдущая нода выдает список (иконка массива []), а не единичный объект. Если данных нет, добавьте ноду Edit Fields (Set) для принудительного создания массива.

Практическое задание

  1. Создайте HTTP Request, который получает данные по адресу https://jsonplaceholder.typicode.com/posts.
  2. Добавьте ноду Split In Batches с Batch Size = 1.
  3. Подключите ноду Set, которая берет поле title из текущего элемента и переименовывает его в processed_title.
  4. Замкните выход ноды Set на вход ноды Split In Batches.
  5. Нажмите Execute Workflow и в панели Execution History пронаблюдайте, как нода Split In Batches последовательно меняет значение счетчика итераций для каждого объекта из JSON-ответа.
