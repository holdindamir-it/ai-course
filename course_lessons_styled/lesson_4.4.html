Урок 4.4. Системные промпты: создаём «персонажа» для корпоративного бота

1. Суть инструмента: Системный промпт

Системный промпт — это скрытая инструкция, которая определяет поведение языковой модели до того, как она получит основной запрос пользователя. С точки зрения архитектуры n8n, системный промпт задает контекстуальные границы и формат выходных данных (например, JSON или структурированный текст), предотвращая галлюцинации и отклонения модели от заданного алгоритма.

Модель использует эту инструкцию как фундаментальный приоритет. Если в системном промпте указано строго классифицировать данные на категории "Вопрос" и "Заказ", модель будет игнорировать любые попытки пользователя сменить тему или нарушить структуру вывода. Это превращает LLM из чат-бота в предсказуемый функциональный компонент автоматизации.

2. Интерфейс и логика настройки в n8n

Для реализации задачи классификации используется нода AI Agent в связке с моделью (например, OpenAI Chat Model). Настройка логики происходит в следующих полях:

  • System Message: Находится внутри настроек ноды AI Agent или подключенного AI Memory / Prompt блока. Здесь вы прописываете правила: "Ты классификатор. Если текст содержит '?', верни 'Вопрос'. Если содержит цифры, верни 'Заказ'. Вывод строго в формате JSON: {"category": "...", "value": "..."}."
  • JSON Output Parsing: В ноде AI Agent или последующей ноде Code необходимо включить принудительное чтение данных. Это позволяет извлечь значения из ответа модели для передачи в Google Sheets.
  • Google Sheets (Append Row): В этой ноде вы указываете Resource: Row и Operation: Append. В полях колонок необходимо сопоставить ключи из вашего системного промпта (category и value) с заголовками столбцов в Google Таблице.
  • Expression Editor: Используется для динамической подстановки данных. Чтобы передать результат классификации в таблицу, вы нажимаете кнопку Expression в поле ввода Google Sheets и перетаскиваете (drag-and-drop) нужные переменные из выходных данных ноды AI Agent.

Важно: Если формат ответа модели нестабилен, используйте в настройках модели параметр Response Format, установив его в значение JSON Object. Это обеспечит строгое соответствие данных структуре, которую ожидает Google Sheets.

1. Пошаговая инструкция настройки

  • Настройка AI Agent: Откройте ноду AI Agent. В разделе System Message введите текст: "Анализируй текст. Если содержит '?', отвечай JSON: {"type": "Вопрос", "value": 0}. Если содержит цифру, отвечай JSON: {"type": "Заказ", "value": [число]}. Если ничего не подходит, отвечай JSON: {"type": "Прочее", "value": 0}."
  • Подключение Google Sheets: Добавьте ноду Google Sheets, выберите операцию Append. Укажите ID вашего файла и название листа.
  • Маппинг данных: Нажмите кнопку Add Field в ноде Google Sheets. В поле Value нажмите на иконку Expression. В открывшемся окне найдите ветку AI Agent, раскройте её и выберите поле output (или содержимое JSON-ответа). Убедитесь, что данные корректно подтянулись в колонки.
  • Тестирование: Нажмите кнопку Test Step в каждой ноде по очереди, начиная с Webhook, чтобы проверить прохождение данных.

2. Почему это ломается: Ошибки и решения

  • Ошибка парсинга JSON: Модель добавила лишний текст до или после JSON. Решение: В системном промпте добавьте фразу: "Возвращай ТОЛЬКО чистый JSON без пояснительного текста".
  • Конфликт типов данных: Google Sheets ожидает число, а модель передала строку "100". Решение: В настройках Google Sheets, в поле выбора колонки, измените формат ячейки на "Текст" или используйте ноду Edit Fields перед таблицей для принудительного изменения типа данных.
  • Отсутствие данных в ответе: Пользователь отправил пустое сообщение, и нода AI Agent вернула ошибку из-за отсутствия входного текста. Решение: Добавьте ноду If до AI Agent, где условие: "Если поле сообщения не пустое (isEmpty = false)".

3. Практическое задание

  1. Реализуйте описанную выше схему в рабочем пространстве n8n.
  2. Добавьте ноду Set после AI Agent, чтобы с помощью функции JSON.parse (через интерфейс Code-ноды или визуальный Expression) гарантированно разделить ответ модели на два отдельных поля для Google Sheets.
  3. Выполните три тестовых запуска через Webhook URL:
    • Отправьте "Сколько стоит?".
    • Отправьте "Хочу 500 штук".
    • Отправьте "Привет".
  4. Проверьте Execution History: убедитесь, что в Google Таблицу корректно записаны значения во всех трех случаях.
