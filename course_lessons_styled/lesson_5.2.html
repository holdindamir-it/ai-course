Урок 5.2. Нода OpenAI в n8n: Chat, Completion, Embeddings — что выбрать

Суть инструментов OpenAI в n8n

Нода OpenAI в n8n — это программный интерфейс для взаимодействия с вычислительными моделями компании OpenAI. Технически она работает по принципу API-запроса: n8n отправляет данные на сервер OpenAI, модель обрабатывает их согласно заданным алгоритмам, и возвращает структурированный JSON-ответ. Вы не запускаете нейросеть локально, а используете готовый вычислительный ресурс через облачное соединение.

Выбор режима работы ноды определяет тип операции, которую вы запрашиваете у модели. Каждый режим требует специфической структуры входных данных и возвращает ответ в разном формате, что критически влияет на дальнейшую обработку информации внутри вашего сценария автоматизации.

Разбор операций и интерфейса ноды

В настройках ноды OpenAI поле Operation является определяющим для логики вашего процесса:

  • Chat (Chat Completion): Основной режим для ведения диалога. Вы передаете массив сообщений (роль System задает поведение, User — ваш запрос). Используйте этот режим для 95% задач автоматизации: написание текстов, анализ данных или классификация запросов.
  • Completion: Устаревший формат (Legacy). Используется для генерации продолжения текста. В отличие от Chat, он не поддерживает концепцию контекстного диалога. В современной разработке практически не применяется, заменяется на Chat с моделью gpt-3.5-turbo или gpt-4o.
  • Embeddings: Режим для преобразования текста в числовой вектор (массив чисел). Этот режим не генерирует текст. Он используется для подготовки данных к поиску по сходству или созданию баз знаний (векторных баз данных). Результат операции — массив чисел, который нельзя отправить пользователю как ответ, но можно использовать для сравнения смыслов разных документов.

Технические поля интерфейса

  • Resource: Выбираем "Chat" для большинства задач.
  • Model: Поле для выбора идентификатора модели (например, gpt-4o или gpt-4o-mini). От модели зависят стоимость запроса и лимит токенов (объем текста).
  • Messages: Ключевой блок настройки. Здесь вы добавляете элементы (Add Item). Каждый элемент имеет поле Role (System, User, Assistant) и Content (сам текст сообщения).
  • Options: Здесь находятся параметры Temperature (от 0 до 1). 0 — делает модель предсказуемой (подходит для работы с данными), 1 — делает модель более вариативной и "творческой".

При выборе Embeddings интерфейс ноды меняется: исчезает поле Messages и появляется поле Text, куда подается строка для векторизации. На выходе нода вернет объект embedding, содержащий список значений с плавающей запятой.

Практическая настройка: переход от Chat к Embeddings

Для переключения логики работы ноды выполните следующие действия:

  • Откройте ноду OpenAI в вашем сценарии.
  • В выпадающем списке Operation выберите значение Embed.
  • В поле Text нажмите кнопку Add Expression. В открывшемся окне выберите данные из входящего Webhook, например, {{ $json.body.message }}.
  • В поле Model выберите актуальную версию, например, text-embedding-3-small.
  • Нажмите кнопку Execute Node. В окне вывода вы увидите массив чисел (вектор), а не текст. Это означает, что данные успешно преобразованы для машинного анализа.

Технические причины сбоев и их устранение

  • Ошибка 401 (Unauthorized): Проблема в Credentials. Решение: Перейдите в настройки Credentials ноды OpenAI, убедитесь, что API Key скопирован без лишних пробелов в начале или конце. Проверьте статус аккаунта в личном кабинете OpenAI (наличие активных кредитов).
  • Ошибка 429 (Rate Limit): Вы превысили лимит запросов в минуту или объем токенов. Решение: В настройках ноды (вкладка Settings) включите Retry On Fail. Это заставит n8n повторить запрос через короткий промежуток времени автоматически.
  • Несоответствие структуры данных: Попытка вывода поля content в Respond to Webhook после операции Embeddings. Решение: Поскольку Embeddings не возвращает поле content, ваш Webhook выдаст ошибку "Undefined". Используйте ноду Edit Fields (Set) перед ответом, чтобы создать статичное сообщение: "Векторизация завершена", если поле content отсутствует в выходных данных.

Практическое задание

  1. Создайте дубликат текущего сценария.
  2. В ноде OpenAI настройте режим Chat, добавьте роль System с инструкцией: "Ты — технический ассистент, отвечай только цифрами".
  3. Подключите ноду Edit Fields (Set) между OpenAI и Webhook. В ней добавьте поле result, в значении которого используйте выражение для получения первого элемента массива {{ $json.choices[0].message.content }}.
  4. Протестируйте цепочку: отправьте запрос через Postman, убедитесь, что в ответе пришло только число.
  5. Измените операцию на Embeddings и посмотрите в логах Execution Data, как меняется структура JSON (исчезает поле choices и появляется поле embedding).
