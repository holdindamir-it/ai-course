Урок 2.2. Google Sheets: читаем, пишем, обновляем строки автоматически

Суть работы Google Sheets как базы данных

Google Sheets в автоматизации используется как хранилище данных (база данных плоского типа). Каждая строка в таблице воспринимается системой как отдельный объект (JSON-объект), где заголовки столбцов становятся ключами, а ячейки — значениями.

Процесс работы строится на HTTP-запросах к API Google. Нода n8n преобразует действия пользователя в эти запросы, позволяя считывать диапазоны ячеек, добавлять новые записи в конец листа или изменять существующие данные по определенному условию (фильтру).

Основные операции и логика управления

Для взаимодействия с данными используются следующие поля внутри ноды Google Sheets:

  • Resource: определяет объект манипуляции. Выбираем Row для работы с записями или Spreadsheet для управления метаданными файла.
  • Operation: выбор действия.
    • Append — добавляет новую строку в самый низ таблицы.
    • Update — изменяет данные в конкретной строке (требует указания номера строки или уникального ключа).
    • Get Many — считывает массив данных из указанного диапазона (например, A1:D100).
  • Sheet Name: точное название вкладки в нижней части вашего документа Google Sheets. Оно должно совпадать до символа, включая пробелы.
  • Options / Column To Match On: критический параметр для обновления данных. Позволяет системе найти строку, которую нужно изменить, основываясь на совпадении данных (например, искать строку, где столбец "Email" равен значению из предыдущей ноды).
  • Value to Match: значение, по которому система ищет строку в таблице.
  • Columns: блок полей для сопоставления данных из автоматизации с заголовками столбцов в таблице (Mapping). В левое поле вписывается имя заголовка из таблицы, в правое — передаваемое значение из предыдущих нод.

Алгоритм настройки записи данных

  • Добавьте ноду Google Sheets и выберите операцию Append.
  • Укажите Sheet Name, соответствующее вашей вкладке.
  • Нажмите кнопку Add Field в разделе Columns.
  • Введите точное название заголовка вашего столбца в поле Column Name.
  • В поле Value с помощью кнопки с иконкой шестеренки выберите Add Expression для динамической подстановки данных из предыдущих шагов процесса.
  • Нажмите Execute Node для отправки тестовой записи в таблицу.

Пошаговая настройка обновления существующей строки

  • Добавьте на холст новую ноду Google Sheets и соедините её с предыдущим этапом, откуда приходят обновленные данные.
  • В поле Resource выберите Row, в поле Operation выберите Update.
  • В поле Lookup Column введите название столбца, в котором находится уникальный идентификатор (например, ID или Email).
  • В поле Lookup Value кликните на иконку шестеренки -> Add Expression. В открывшемся окне перетащите переменную из левой панели (Input), которая содержит значение для поиска.
  • В блоке Update Key нажмите кнопку Add Field, выберите название столбца, который нужно обновить, и введите новое значение или также выберите его через Expression.
  • Нажмите Execute Node. Если в таблице найдена строка с соответствующим Lookup Value, данные будут перезаписаны.

Технические причины сбоев и способы устранения

  • Ошибка "Sheet name does not exist": Возникает из-за несоответствия имени вкладки в настройках ноды и внизу интерфейса Google Sheets. Решение: скопируйте имя вкладки прямо из интерфейса Google Sheets (Ctrl+C) и вставьте его в поле Sheet Name в n8n, убедившись в отсутствии лишних пробелов.
  • Ошибка "Column not found": Возникает, если в настройках ноды указано название столбца (Column Name), которого нет в первой строке вашей таблицы. Решение: проверьте первую строку Google Sheets. Она должна содержать заголовки, идентичные тем, что указаны в ноде. Убедитесь, что вы не используете объединенные ячейки в заголовках.
  • Ошибка "403 Permission Denied": Возникает при попытке записать данные в таблицу, к которой у сервисного аккаунта или OAuth-пользователя нет прав на редактирование. Решение: откройте таблицу в Google, нажмите кнопку Поделиться и выдайте права Редактор тому email-адресу, который используется в ваших Credentials (обычно это email сервисного аккаунта или ваш личный аккаунт).

Практическое задание для закрепления

Выполните следующие действия в своем сценарии:

  1. Создайте в таблице два столбца: Name и Status.
  2. Добавьте одну строку с данными: Ivan в колонку Name и Pending в колонку Status.
  3. Настройте ноду Google Sheets с операцией Update так, чтобы при запуске сценария статус Ivan менялся с Pending на Done.
  4. Используйте Lookup Column: Name и Lookup Value: Ivan.
  5. Проверьте изменение значения в интерфейсе Google Sheets после нажатия Execute Node.
