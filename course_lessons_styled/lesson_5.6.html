Урок 5.6. Альтернативы OpenAI: Mistral, Claude API, Gemini (через HTTP Request)

Принцип работы HTTP Request для взаимодействия с LLM

Внешние языковые модели (Mistral, Claude, Gemini) предоставляют доступ к своим мощностям через API. Для взаимодействия с ними в n8n не используются специализированные ноды, а применяется универсальная нода HTTP Request. По сути, это отправка структурированного JSON-запроса на определенный адрес (Endpoint) провайдера с передачей уникального ключа доступа в заголовках (Headers). Ответ от сервера приходит в том же формате, который затем парсится для извлечения текстового результата.

Интерфейс и настройка ноды HTTP Request

Для подключения сторонней модели в n8n необходимо выполнить следующие действия в интерфейсе ноды HTTP Request:

  • Method: Выбирается POST, так как мы отправляем данные для обработки.
  • URL: Указывается адрес API провайдера (например, https://api.anthropic.com/v1/messages для Claude или https://generativelanguage.googleapis.com/... для Gemini).
  • Authentication: Выбирается тип Header Auth. В поле Name вводится ключ авторизации (например, x-api-key для Claude), а в Value — токен, полученный в личном кабинете разработчика модели.
  • Send Body: Устанавливается значение true.
  • Body Parameters: Выбирается формат JSON. В открывшемся поле ввода формируется тело запроса. Оно строго соответствует документации API конкретной модели и обычно содержит параметры model (название версии ИИ) и messages (массив объектов с текстом пользователя).
  • Response Format: Устанавливается JSON, чтобы n8n автоматически преобразовал ответ сервера в объект, доступный для дальнейшей обработки в следующих нодах сценария.

Важно: каждая модель имеет уникальную структуру JSON-запроса. Перед заполнением поля Body необходимо открыть документацию API (например, API Reference для Gemini) и скопировать структуру тела запроса, заменив статические данные на динамические переменные из предыдущих нод через выражение {{ $json.message }}.

Пошаговая настройка интеграции (на примере Anthropic Claude)

  • Откройте редактор n8n, перетащите на рабочее поле ноду HTTP Request.
  • В параметре Method выберите POST.
  • В поле URL вставьте официальный API endpoint (например, https://api.anthropic.com/v1/messages).
  • Перейдите в раздел Authentication, выберите Header Auth, нажмите Create New Credential. В поле Name введите x-api-key, в Value — ваш секретный токен из консоли разработчика.
  • В поле Send Body поставьте true, выберите формат JSON.
  • В поле JSON Parameters нажмите Add Option -> Body Parameters. Нажмите кнопку Add Field, выберите тип Object, назовите его messages, добавьте внутрь строку content и вставьте переменную из предыдущего узла через выражение {{ $json.text }}.
  • Нажмите Execute Node для проверки связи.

Типичные ошибки и методы их устранения

  • Ошибка 401 Unauthorized: Возникает из-за неверного ключа или ошибки в названии заголовка. Решение: Проверьте в разделе Authentication, совпадает ли имя заголовка с тем, что требует документация API конкретного сервиса.
  • Ошибка 400 Bad Request (Malformed JSON): Возникает при нарушении структуры JSON-тела. Решение: Убедитесь, что все открывающие скобки { имеют соответствующие закрывающие }, а вложенные массивы данных соответствуют формату, указанному в документации провайдера.
  • Ошибка 429 Too Many Requests: Возникает при исчерпании лимитов на количество запросов в минуту. Решение: Добавьте ноду Wait перед HTTP Request, чтобы принудительно замедлить выполнение сценария.

Практическое задание

  • Зарегистрируйтесь в консоли Google AI Studio, получите API Key для модели Gemini.
  • Добавьте ноду HTTP Request в свой текущий сценарий после получения сообщения из Telegram.
  • Настройте ноду так, чтобы текст из Telegram передавался в параметр parts (текстовое сообщение) модели Gemini.
  • Используйте ноду Edit Fields (Set) после HTTP Request, чтобы извлечь только текст ответа из длинного JSON-ответа, который присылает сервер.
  • Соедините выход этой ноды с нодой Telegram (Send Message), чтобы бот отвечал пользователю сгенерированным текстом.
  • Протестируйте сценарий, отправив боту произвольный вопрос, и убедитесь, что в Telegram приходит ответ от модели.
