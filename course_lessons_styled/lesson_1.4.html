Урок 1.4. Условия и фильтры (нода IF): делаем автоматизацию «умной»

Суть ноды IF: логическая маршрутизация данных

Нода IF — это логический вентиль, который разделяет поток данных на две ветки: true (истина) и false (ложь). Она принимает на вход объект из предыдущей ноды, сравнивает значение указанного поля с заданным условием и направляет исполнение сценария по соответствующему пути.

В отличие от простого прохождения данных, использование IF позволяет создавать ветвление: если условие выполняется, автоматизация идет по одной цепочке нод; если нет — по другой, или вовсе останавливает выполнение конкретной ветки.

Интерфейс и настройка логики

Для активации логического условия выполните следующие действия в редакторе n8n:

  • Добавление ноды: Нажмите на знак «+» после ноды Set Node и в поиске введите IF. Выберите её из списка доступных нод.
  • Поле Value 1: Сюда через Expression Editor передается значение из предыдущей ноды (например, поле title, полученное от HTTP Request).
  • Оператор (Operation): Меню выбора логического сравнения. Основные варианты:
    • Equal — значение в поле 1 в точности совпадает с полем 2.
    • Not Equal — значения не совпадают.
    • Contains — значение в поле 1 содержит внутри себя подстроку из поля 2.
    • Greater Than / Less Than — сравнение числовых значений.
  • Поле Value 2: Константное значение или переменная, с которой вы сравниваете данные из Value 1.
  • Ветки вывода: После настройки ноды IF вы увидите два порта вывода:
    • Верхний порт (с иконкой галочки): true. Сюда подключаются ноды, которые должны сработать при выполнении условия.
    • Нижний порт (с иконкой крестика): false. Сюда подключаются ноды, которые должны сработать, если условие не выполнено.

Практическая настройка ноды IF

Для внедрения условия в вашу текущую схему выполните следующие шаги:

  • Нажмите на соединительную линию между Set Node и любой следующей нодой (или на выходной порт Set Node) и выберите в поиске If.
  • В панели настроек ноды If нажмите кнопку Add Condition.
  • В поле Value 1 нажмите на шестеренку, выберите Add Expression. В открывшемся окне найдите в списке Current Node -> Output Data -> json -> title.
  • В выпадающем списке Operation выберите Contains.
  • В поле Value 2 введите текстовую строку, например: sunt.
  • Закройте окно настроек. Теперь от ноды If отходит два выхода. Соедините верхний выход (true) с новой нодой Edit Fields (Set), в которой напишите сообщение «Условие выполнено».

Типичные причины сбоев и способы устранения

  • Несоответствие типов данных: Вы пытаетесь сравнить строку с числом (например, 1 как текст и 1 как число). Решение: В поле Value 2 выберите тип данных, соответствующий данным из Value 1, или используйте приведение типов в Expression Editor.
  • Пустые значения (Null): Поле, которое вы проверяете, отсутствует в ответе от сервера (сервер вернул пустой объект). Решение: Добавьте перед нодой If ноду If (или Switch) с проверкой на наличие данных через оператор Is Set.
  • Чувствительность к регистру: Использование оператора Equal для текста, где различаются заглавные и строчные буквы. Решение: Используйте оператор Contains или переключите опцию Ignore Case (если доступно в версии ноды), чтобы игнорировать регистр.

Практическое задание

  1. Самостоятельно настройте ноду If так, чтобы она проверяла, содержит ли поле title слово aut.
  2. Подключите к выходу true ноду Set, которая устанавливает параметр result в значение "Совпадение найдено".
  3. Подключите к выходу false ноду Set, которая устанавливает параметр result в значение "Совпадение не найдено".
  4. Нажмите Execute Workflow и через вкладку Output убедитесь, что значение в result соответствует логике вашего запроса к JSONPlaceholder.
