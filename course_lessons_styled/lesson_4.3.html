Урок 4.3. Промпты для бизнеса: обработка заявок, ответы, классификация данных

1. Суть инструмента: обработка текстовых данных через LLM

Инструмент "Промпт" — это набор инструкций, который передается нейросетевой модели для обработки входного текста. В контексте автоматизации это работает как фильтр: на вход ноды подается неструктурированный текст (например, сообщение пользователя), а на выход подается структурированный ответ, соответствующий заданным правилам (JSON, число, конкретная фраза).

В n8n модель выступает в роли обработчика, который анализирует содержание сообщения, выполняет логические проверки (если-то) и преобразует данные в формат, пригодный для записи в ячейки Google Sheets. Это позволяет автоматизировать классификацию заявок без написания сложного программного кода.

2. Разбор интерфейса и логики ноды

  • Нода AI Agent или OpenAI/Anthropic: Основной узел для взаимодействия. В поле System Message задается поведение модели. Это критическая зона: всё, что здесь написано, является "законом" для обработки входящего потока данных.
  • Поле Input: Сюда через механизм Expression передается переменная из предыдущих нод (например, текст из входящего email или сообщения в Telegram). Иконка шестеренки или "плюс" рядом с полем позволяет выбрать объект {{ $json.message }}.
  • Output Parser (Парсер вывода): Нода, которая преобразует "сырой" ответ нейросети в формат, понятный для последующей передачи в Google Sheets. При работе с классификацией данных рекомендуется выбирать формат Structured Output, где вы задаете схему данных (имя поля и тип данных — String, Number).
  • Меню "Prompt Options": Находится внутри настроек ноды модели. Параметр Temperature определяет "креативность". Для обработки заявок и классификации установите значение 0. Это заставит модель давать предсказуемые и строго логические ответы без "фантазий".
  • Mapping (Сопоставление): После выполнения ноды AI, в ноде Google Sheets в поле Columns to Send необходимо выбрать выходную переменную из ноды AI. Это связывает результат обработки текста с конкретной колонкой таблицы.

1. Пошаговая инструкция настройки

  • Откройте редактор n8n и добавьте ноду OpenAI (или аналогичную модель).
  • В поле System Message введите: "Ты — классификатор заказов. Если в тексте есть число, извлеки его. Если число > 5000, верни строку 'БОЛЬШОЙ ЗАКАЗ'. Если числа нет, верни '0'".
  • В поле Prompt нажмите на иконку с плюсом и выберите $json.body (текст сообщения от пользователя).
  • Нажмите Execute Node для теста. В блоке Output вы увидите результат работы вашей инструкции.
  • Добавьте ноду Google Sheets, выберите действие Append.
  • В поле Columns to Send нажмите Add Field, введите имя столбца, а в поле значения выберите через выражение (Expression) результат работы ноды AI.

2. Почему это ломается: типичные ошибки

  • Несоответствие типов данных: Модель может вернуть строку "5000", а Google Sheets ожидает число. Решение: В настройках ноды Google Sheets проверьте тип данных колонки или используйте выражение {{ parseInt($json.output) }} для принудительного приведения к числу.
  • "Галлюцинации" модели: При температуре выше 0 модель может добавить лишний текст (например, "Конечно, вот ваш результат: 6000"). Решение: Установите Temperature строго в 0 и в System Message добавьте: "Отвечай только результатом, без дополнительных слов".
  • Пустой ввод (Empty Input): Если пользователь прислал эмодзи или пустое сообщение, модель может вернуть ошибку или null. Решение: В настройках ноды AI активируйте опцию Continue On Fail или используйте ноду If до AI-обработки, чтобы отсеивать пустые сообщения.

3. Практическое задание

  1. Создайте в n8n связку: Webhook -> AI Agent -> Google Sheets.
  2. Настройте System Message так, чтобы модель классифицировала текст на два типа: "Вопрос" (если есть знак вопроса) и "Заказ" (если есть число).
  3. В Google Sheets выведите результат классификации в одну колонку, а само число (или 0) — в соседнюю.
  4. Отправьте через Webhook три сообщения: "Привет?", "Куплю 100", "Просто текст". Убедитесь, что в таблице появились соответствующие категории.
