Урок 5.7. Проект: «Умный секретарь» (бот читает вопрос, GPT отвечает)

1. Суть инструмента: HTTP-запросы и JSON

В рамках проекта «Умный секретарь» n8n выступает в роли посредника между Telegram и нейросетью Gemini. Механизм работы основан на протоколе HTTP: когда бот получает ваше сообщение, он отправляет его на сервер Google в виде структурированного пакета данных (JSON). Этот пакет содержит ваш вопрос, инструкции для модели и API-ключ для авторизации.

Сервер обрабатывает запрос и возвращает ответ также в формате JSON — это многоуровневая структура данных, где полезный текст скрыт внутри вложенных массивов и объектов. Задача инженера — правильно настроить отправку данных и выделить нужную текстовую строку из полученного массива для последующей отправки пользователю.

2. Разбор интерфейса и логики нод

  • HTTP Request (Метод POST): Основной узел для передачи данных. В поле URL вставляется адрес API Google. В разделе Send Body необходимо выбрать тип JSON. В поле Body Parameters создается структура, соответствующая спецификации API: ключ contents, содержащий массив объектов с вложенным ключом parts и массивом text.
  • Authentication: В настройках ноды HTTP Request выбирается тип Header Auth. Вы добавляете заголовок x-goog-api-key, куда вставляете полученный ранее ключ. Это авторизует ваш запрос на стороне Google.
  • Edit Fields (Set): Эта нода используется для «фильтрации» ответа. После выполнения запроса нода HTTP Request выведет массив данных. В поле Mapping Mode вы используете путь к данным: json.candidates[0].content.parts[0].text. Это извлекает только сгенерированный текст из технического ответа сервера.
  • Telegram (Send Message): Финальная точка сценария. В поле Chat ID используется переменная {{$json.message.chat.id}} из триггера Telegram, а в поле Text подставляется результат обработки из ноды Edit Fields.
  • Execution (Запуск): Кнопка Execute Workflow в верхней панели n8n запускает процесс. При возникновении ошибки нода подсвечивается красным — при клике на неё в правой панели отображается системный лог с кодом ошибки (например, 401 Unauthorized при неверном ключе или 400 Bad Request при ошибке в структуре JSON).

1. Пошаговая практическая настройка

  • Откройте редактор n8n, нажмите кнопку + в конце цепочки и выберите ноду HTTP Request.
  • В поле Method выберите POST. В поле URL вставьте: https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent?key=ВАШ_API_KEY.
  • Нажмите Send Body -> JSON. В блоке Body Parameters нажмите Add Field, выберите Add JSON. Вставьте конструкцию: {"contents": [{"parts": [{"text": "Текст вопроса"}]}]}. Замените "Текст вопроса" на выражение {{$json.message.text}}, выбрав его из выпадающего списка переменных Telegram.
  • Добавьте ноду Edit Fields (Set). Нажмите Add Field -> String. В поле Name напишите answer. В поле Value нажмите на иконку шестеренки -> Add Expression. В появившемся окне найдите в списке выходных данных ноды HTTP Request путь: candidates -> 0 -> content -> parts -> 0 -> text.
  • Добавьте ноду Telegram, действие Send Message. В Chat ID выберите переменную {{$json.message.chat.id}} из триггера. В Text выберите переменную {{$json.answer}} из ноды Edit Fields.

2. Ошибки и методы их устранения

  • Ошибка 401 (Unauthorized): Проблема в API-ключе. Решение: Проверьте, что ключ вставлен целиком в URL или в заголовок без лишних пробелов или спецсимволов. Пересоздайте ключ в Google AI Studio, если статус не меняется.
  • Ошибка 400 (Bad Request): Ошибка в структуре JSON. Решение: Убедитесь, что JSON в ноде HTTP Request валиден (все кавычки закрыты, структура вложенности contents -> parts -> text соблюдена). Если используется выражение, убедитесь, что оно обернуто в двойные кавычки.
  • Ошибка 500 (Internal Server Error): Переполнение или сбой модели. Решение: Нажмите кнопку Execute Node отдельно на HTTP Request, чтобы увидеть детали ошибки в правой панели. Часто это означает, что модель заблокировала запрос из-за нарушения политики безопасности или превышения лимитов квоты в консоли Google.

3. Практическое задание

  • Создайте «режим эха» внутри ноды Edit Fields: добавьте второе поле, которое к ответу нейросети добавляет приписку (Отвечено моделью Gemini) через оператор конкатенации в выражении (Expression Editor).
  • Протестируйте сценарий: отправьте боту длинный вопрос, содержащий более 20 слов, чтобы проверить, корректно ли нода Edit Fields извлекает полный объем текста без обрезания.
  • Переименуйте все ноды в сценарии (кнопка карандаша в заголовке ноды), чтобы они логически назывались: «Telegram Trigger», «Gemini API», «Extract Text», «Send to User».
